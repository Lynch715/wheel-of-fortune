# 命运之轮 · 万界人生模拟器

> 万界如轮，轮有五辐。轮转一格，停在哪一辐，便生在哪一界。

单文件 HTML，双击就能玩。接一个 OpenAI 兼容的接口，剩下的全在你自己的浏览器里跑。

## 五界

| | | |
|---|---|---|
| ☯ **东荒** | 仙佛妖魔，灵气修成法力 | 天庭管仙籍，地府管生死，灵山管佛门，山里有妖王 |
| ✠ **西陆** | 王国与教廷，魔法与斗气 | 骑士团、魔法塔、封地与边墙 |
| ⛩ **樱洲** | 幕府与妖怪，咒力与气 | 城下町、道场、神社、阴阳寮、忍村、学园 |
| ◎ **轮枢** | 万界交汇之城，只可前往，不可投胎 | 冒险者公会、命运神殿、万界商盟、黑市 |
| ☠ **幽墟** | 魔族深渊，去得了，回得来的少 | 只能从轮枢下去，且只在界门松动那两个月 |

投胎只在前三界。轮枢和幽墟去得了，生不了。

## 几件想做对的事

**成败不归模型管。** 掷骰、判定、比武推演、算钱、算寿元、判伤残、排万界榜，全在前端算完；模型只负责把算完的结果写成故事，不许改，也不许反转。掷 20 必成、掷 1 必败，写在提示词里，三处判定（按钮、自由输入、面谈）用的是同一把尺子。

**出身跟着你一辈子。** 东荒人走到西陆，修的还是灵气那一套，境界还叫金丹，不会因为换了地方就变成「四阶」。拜了本地的师门能给你资源和门路，教不了你原来那条路。代价是异界之身修行慢、开销高——除非你把那道坎了断掉，而那件事只有幽墟办得成。

**界不是皮肤。** 每一界有自己的纪年、称呼、起名路数、势力类型、地名、禁词。东荒的正文里不会冒出「魔法」，樱洲的不会冒出「金丹」。跨界泄漏有自动检查，六十局跑量里一次没漏过。

**自由度是四个旋钮，不是一个。** 行动自由度（言出法随到什么地步）、世道凶险（死伤、仇家、判定门槛）、成长尺度（修为上限、寿元、修炼快慢）、世道厚道（收益、别人肯不肯帮你）。想要主角光环又想要世道凶险，调得出来。

**言出法随也有边界。** 最松那一档玩家说成就成，但改不了已经发生的事——死了的人不会活过来，账上记着的事不能当没发生，终身旧伤不会痊愈。

## 怎么玩

1. 下载 `index.html`，双击打开（或者直接点上面那个链接）。
2. 在设置里填一个 OpenAI 兼容接口的地址、密钥、模型名。推荐 `deepseek-v4-flash`，快且便宜。
3. 转轮，投胎，开始。

密钥只存在你自己浏览器的 localStorage 里，不上传任何地方。存档也在本地。

## 自测

```
node test/s1.js      # 换皮跑通
node test/s2.js      # 五辐、换界、名录、记忆分层
node test/s3.js      # 目标卡、判定、自由度四组
node test/s4.js      # 美术接入
node test/s5.js      # 幽墟
node test/phone.js   # 手机适配
RUNS=20 node test/run.js   # 跑量：三个出生界各 20 局
```

需要 `npm i playwright`。测试用的是内置的假接口（`test/mock.js`），不花钱、不联网。

## 美术
