## 这是什么

单文件 HTML，双击就能玩，不用装任何东西。一回合一个月，一年十二回合，从 1300 到 1400 这一百年里随机开局。

出身抽签：王室 2%、贵族 5%、骑士 8%、教士 10%、中产 25%、贫民 35%、奴隶 10%。抽到什么就是什么，之后怎么活才由你定。

## 几件想做对的事

**历史不能瞎写。** 内置 1300–1400 的君主表、战役年表、黑死病逐年推进、教会大分裂、两场农民起义。每一回合只把那一年真的在世、在位、正在发生的东西喂给模型，名录之外的历史人名一律不许出现——生成完还要正则扫一遍，撞上了就重写。

**数值不归模型管。** 掷骰、判定、算钱、算孕率、判死亡、排继承顺位，全部在前端算完；模型只负责把算完的结果写成故事，不许改，也不许反转。

**钱是真的钱。** 按磅/先令/便士记账（1 磅 = 20 先令 = 240 便士），工价、粮价、租子、什一税、罚金都按史料的档次走。破产会举债，债还不上会卖地，地卖完了阶级就往下掉。

**不许有孤立的属性。** 刺绣绣得好每月就多一笔活计钱；狩猎练到家口粮就省下两成；纹章学认得盾徽，战阵上才知道该抓谁换赎金；恶名高了主君会疏远你、罚金会加重、仇家会找上门。做过的事会回来找你——圈过地的庄子更容易闹民变，放过债的更容易吃官司。

**没有超自然。** 没有神迹、诅咒、预言应验。有人信这些，那是他们的心思，不是世界的规则。瘟疫就是瘟疫。

## 怎么玩

直接开[在线版](https://lynch715.github.io/wheel-of-fortune/)，或者把 `index.html` 存下来双击。

不填 API key 也能玩，走的是本地文案。想要模型写的叙事，在「设置」里填一个 OpenAI 兼容的 key（默认 DeepSeek），只存在你自己浏览器的 localStorage 里，不经过任何服务器。

## 美术

64 张人像 + 12 张场景，泥金手抄本 × 北方文艺复兴油画。全部内嵌在 `index.html` 里（webp，共 464 KB），离线也有图。出图的完整规范和提示词模板在[施工文档](规范与施工流程_v0.1.md)第 5 章。

`art/` 里只留了图标和封面，原图没进仓库。
